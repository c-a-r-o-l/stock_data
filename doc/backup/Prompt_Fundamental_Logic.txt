/research

Objective:

Build a library of stock fundamental events that have demonstrated predictive power for future stock returns.

Only include events supported by empirical evidence, academic research, institutional factor investing literature, or long-term practitioner validation.

Priority 3:

==========================================================
EXCLUDE
=======

Exclude:

* Pure opinions
* Unverified blog posts
* Single-stock anecdotes
* Technical indicators
* Day trading signals
* Signals without historical testing
* Signals without clear thresholds

==========================================================
RESEARCH GOAL
=============

Identify fundamental events that consistently predict:

* 3 month forward return
* 6 month forward return
* 12 month forward return
* 24 month forward return

Focus on:

* Revenue Growth
* EPS Growth
* Earnings Revisions
* ROE
* ROIC
* Gross Margin
* Operating Margin
* Free Cash Flow
* Debt Ratios
* Share Buybacks
* Valuation Ratios
* Asset Growth
* Accruals
* Insider Ownership
* Capital Allocation

==========================================================
FOR EACH EVENT OUTPUT
=====================

Use EXACTLY the following format:

### Event X: [Event Name] ★★★

| Field                  | Content                                                     |
| ---------------------- | ----------------------------------------------------------- |
| Trigger Condition      | Exact formula and threshold                                 |
| Statistical Evidence   | Sample period, hit rate, excess return, Sharpe if available |
| Forward Return Profile | 3M / 6M / 12M / 24M                                         |
| Logic Chain            | Why the event works                                         |
| Threshold Optimization | Best-performing thresholds discovered in literature         |
| Failure Scenarios      | When signal stops working                                   |
| Data Requirements      | Required fundamental fields                                 |
| Data Delay             | Reporting lag and practical implementation                  |
| Empirical Sources      | Papers, books, institutional research                       |
